# numfmt

浏览器单页工作台（原生 ES 模块，零依赖）。

## 起服务看页面

    python3 -m http.server 8000

浏览器打开 http://127.0.0.1:8000/ ，改样例点运行看结果。

## 测试

    node tests/run.js

## 场景自检

    node check_sample.js

## 舍入策略

- 按精度（小数位数）做十进制舍入，半程时向偶数靠（round-half-to-even，
  银行家舍入）：`3.125` 在精度 2 下得 `3.12`，`3.135` 得 `3.14`。
- 舍入基于数值的最短可往返十进制表示，不经过 `* 10^p` 缩放，避免引入
  额外的二进制浮点误差。
- 格式化后去掉多余的零：`2.50` → `2.5`，`10.00` → `10`。
- 发生舍入（格式化结果与原值不相等）的个数计入 `rounded`。
- 精度为负或不是整数时抛出 `E_BAD_PRECISION`。

## 单位约定

- `unit`（如 `ms`）只是展示标签，不参与计算。
- `scale` 是单位换算系数，约定调用方在传入前已把 `values` 换算到目标
  单位；工作台本身不再做二次换算，保证往返比较在同一单位下进行。

## 不变量

- 往返保真：未触发舍入的数值（含所有在精度内可精确表示的二进制值）
  格式化再解析回来与原值完全一致；有偏差的位置列入 `drift`。
- 幂等：同一输入重复格式化结果相同；输出已是规范形（小数位不超过
  精度、末尾无多余的零），再格式化一次不变。
- 预算：格式化与校验都是单次线性遍历，十万个数值不重复格式化。
